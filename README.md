# QRBLauncher Website

Публичный сайт QRBLauncher для GitHub Pages. Исходный код лаунчера хранится отдельно в приватном репозитории.

## Публикация через GitHub Pages

1. Откройте Settings → Pages.
2. В разделе Build and deployment выберите Deploy from a branch.
3. Укажите ветку main и папку /(root), затем нажмите Save.

Ожидаемый адрес: https://saidianstreet-code.github.io/QRBLauncher-Website/

## Публикация QRBLauncher.exe

Исполняемый файл не хранится в Git. Опубликуйте его как Release asset с точным именем QRBLauncher.exe в публичном репозитории QRBLauncher-Website. Кнопка скачивания на сайте ведёт на /releases/latest/download/QRBLauncher.exe.
